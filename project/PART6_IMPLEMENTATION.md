## 已实现内容

**宇宙中心 / 潜水**：大吾与赤焰松的 Mega 队伍及 Multi 战中各自的 Mega 权限，PART5.5 已经实现并有宿主测试，本批没有重做。新增：火岩队新人在宇宙中心门口的事前对话，以及事后她独自离开组织（`FLAG_PART6_ROOKIE_LEFT_MAGMA`，即她实际离开火岩队的节点）。大吾给潜水的原版事件只改了台词。

**潜水世界**：
- 完成 5.5 的海底异常调查（126 号高温水流 / 127 号异常海流 / 128 号未知能量），报酬为进化石 + 大珍珠×3。
- 海底景观：珊瑚区、沉没货箱、古代石柱、阿尔刻海床传感器（126 号潜水员对它有意见）；5 个新隐藏物品。
- 127 号支线：父女珊瑚（心之鳞片×3，可选“很好看 / 有点黑”）、旧潜水灯（潜水球×5 + 珍珠）、潮流记录仪（呆壳兽进化石，5.5 没有发放，所以按稿件在这里给）。
- 129 号工具箱（潜水球×10 + 大珍珠）。
- 130 号沉船（PP 提升剂 + 金珠）、131 号化石样本箱（化石翼龙进化石）。这两条水路原版没有海底地图，所以用海面上“潜下去看看”的短场景代替。
- 海底野生：124 号加轻飘飘 5%，126 号加垃垃藻 5%、好坏星 1%。

**水君**：126 号海底西南的海草区有一道裂隙，可上浮进入新地图“静水洞窟”（复制海底洞穴终点的布局）。水君 Lv40，规则与炎帝/雷公一致：捕获后永久完成；其他结果下暂时离开，下次进入殿堂后重新出现。

**莱因（环境系统负责人）**：
- 绿岭宇宙中心联合观测站：首次登场，台词涉及联盟和原始数据所有权，并说出理念台词。
- 128 号平台：可拒绝的测试战（漂浮泡泡42 / 清洗洛托姆43 / 盔甲鸟43 / 电击魔兽44 / 自爆磁怪46，不 Mega），报酬特性胶囊 + PP 提升剂。
- 127 号渔场冲突：帮忙校准 3 个海底点，第三个点触发警报、船只停下，渔夫让步；报酬 PP 提升剂 + 大珍珠×2。
- 危机中在园区总部：设备资源分配（凯那 vs 暮水）。危机后：疲惫地说“剩下的工作才刚开始”、“六个部门审批”；如果玩家用过调律器，会说“人为的？……算了，数据能用”。

**海底洞窟**：原版迷宫完整保留。新增 3 处环境调查、3 名基层成员的新台词。阿泉保持完整的非 Mega 队伍；水梧桐 5 只，王牌为 Mega 巨牙鲨 Lv47。

**丰缘事变（危机期间）**：沿用凯那、水静、园区、119 天气研究所、釜炎、绿岭、暮水、琉璃的原有 NPC，危机中改说危机台词，部分在危机后再变一次。凯那码头有阿尔刻缓冲设备；园区总部员工谈到“危机期间权限全部批了”。

**琉璃**：
- 生活 NPC 4 人。危机中阿尔刻临时封锁点及“谁的应急协议”对话；危机后路障撤除，传感器留下。
- 临时诊疗点：差不多娃娃 + 急救药箱。差不多娃娃进化石 5.5 已发过，按去重原则改为 PP 极限提升剂 + 全复药×3。
- 走失海豹球（潜水球×5）、沉水相机（神奇糖果 + 豪华球×5）。
- 危机后艾路雷朵挑战（大剑鬼45 / 阿勃梭鲁45 / 劈斩司令46 / Mega 艾路雷朵48，奖励艾路雷朵进化石）。
- 危机后 118 号道路的匿名“男子”赠送本原调律器（台词与 Canon 一致，不暴露身份）。
- 亚当 6 只（Mega 暴鲤龙45 在第五位，刺龙王47 为最高等级），战后多一句台词。
- 觉醒祠堂 3 处壁画文本，米可利的原版引导不变。

**暮水**：
- 木匠收集 3 块漂浮木板（PP 极限提升剂）。
- 居民谈论钓鱼人和阿尔刻用钱租船。原有渔夫改为提示西边潜水点（没有另加 NPC）。
- 萨维尔：危机中只说“风变了。”，危机后“塔上很吵。”；三柱全部捕获后给特性膏药 + 神奇糖果×3。原古空棘鱼赠送保留。
- 布告石室原版封印打开后，可调查得到 PP 极限提升剂。

**天空之柱**：
- 入口洞穴有封锁安保（战斗）。
- 1F 外围安保、3F 生命研究员（百变怪）、5F 技术员 + 护卫双打与高级研究员、顶层伊芙琳（多边兽Z / 美纳斯 / 人造细胞卵 / 艾路雷朵 / Mega 胡地48）。2F 和 4F 有裂地板，没有放训练家。
- 3F 七夕青鸟实验：可放生，奖励神奇糖果（锐利鸟嘴在百货无限出售，属于过度重复）。
- 路线奖励：全复药（3F）、PP 极限提升剂（5F）、顶层储存盒 PP 提升剂。
- 伊芙琳和助手挡住顶层唯一通道，战败后撤离（带走样本），之后原版烈空坐苏醒照常进行。之后各层的阿尔刻人员全部消失，调查点改为“压痕 / 断线 / 封锁牌倒下”。
- 危机后的烈空坐捕获战改为 Lv50，原版的失败 / 逃跑 / 殿堂重置逻辑保留。

**本原调律器**：重要道具，从包里使用。可选晴天 / 降雨 / 沙暴 / 下雪 / 恢复正常。危机期间、室内、海底、天空之柱、琉璃、彩虹城，以及大旱 / 暴雨 / 异常 / 火山灰 / 水下泡泡等特殊天气地图都不能使用。离开地图后天气恢复。水静园区总部的工作人员给出教学任务（晴天、降雨、沙暴各一次），奖励 PP 极限提升剂。

**第八徽章后**：天气研究所的“丰缘环境复查”：确认 4 个节点（119 / 凯那港 / 水静海滨大道 / 绿岭观测站），奖励 PP 极限提升剂 + 神奇糖果×3 + 25000 元。火岩队新人危机后穿便服出现在釜炎温泉旁（暂用野餐少女外观，发色待正式美术处理）。
